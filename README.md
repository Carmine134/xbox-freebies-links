# Xbox freebies link list

Product IDs for free Xbox store items, collected from the TrueAchievements
"List Of Free Content" thread.

`links.json` holds nothing but store product IDs, for example `9NKXLP3BZCSL`.
No account data, and no copied forum content.

Used by [Carmines Xbox Freebies](https://github.com/Carmine134/carmines-xbox-freebies),
which checks each item's price and your ownership before claiming anything.
