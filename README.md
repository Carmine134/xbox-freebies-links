# Xbox freebies: the shared lists

What **Carmines Xbox Freebies** downloads. Nothing here needs an account: the app reads
these files straight from this repository and claims what you are missing.

| File | What it holds |
| --- | --- |
| `links.json` | Store product IDs, for example `9NKXLP3BZCSL`, collected from saved TrueAchievements pages |
| `free-<MARKET>.json` | Everything free in that store right now |
| `newly-free-<MARKET>.json` | What turned free in the last three weeks |
| `catalog.json`, `catalog.csv` | Prices already looked up, so nobody looks them up twice |

Markets covered: US, TR, DE, GB, NO, IS, HU. No account data, and no copied forum content.

## The app

Download **CarminesXboxFreebies.exe** from
[Releases](https://github.com/Carmine134/xbox-freebies-links/releases/latest). It keeps
itself up to date from there, so one download is the last one you need.

Free items are claimed on xbox.com through your own signed-in browser. Prices come from
Microsoft's public catalog, so a free trial is never mistaken for a free game, and
anything free only through Game Pass or Ubisoft+ is left alone.
